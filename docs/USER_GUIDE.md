# USER GUIDE

## How to Play
Farkle Lite is a push-your-luck dice game. Roll dice, select scoring combinations, commit points, and decide when to bank before you FARKLE.

## Controls
- D-pad short: move cursor
- OK short: select/unselect highlighted die
- OK long: roll available (unheld) dice
- Right long: score selected dice
- Down long: bank points and begin a new turn
- Back: exit

## Turn vs Bank
- **Turn**: points currently at risk in the active turn.
- **Bank**: points permanently saved across turns.

If you FARKLE, your unbanked Turn points are lost.

## How Scoring Works
- Only selected dice are scored.
- Selection must be an exact valid scoring set.
- If your selection includes any non-scoring die, the score is invalid (0).

## HOT DICE
When all six dice are scored in one turn:
1. HOT DICE screen appears.
2. All six dice become available again.
3. You continue the same turn with a full reroll.

## FARKLE
If you roll and no scoring subset exists in the newly rolled dice:
1. Roll is shown briefly.
2. Full-screen `FARKLE...` appears.
3. Turn score resets.
4. New full roll starts.

## Example Turn Walkthrough
1. Roll all six dice (OK long).
2. Select a scoring set (for example, a single 1 and single 5).
3. Commit selection (Right long) to add points to Turn.
4. Decide:
   - Roll remaining dice for more points (OK long), or
   - Bank current Turn (Down long).
5. If all six dice are scored, HOT DICE triggers and your turn continues.
